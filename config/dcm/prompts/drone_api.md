# DRONE_API.md
Return native calls matching schemas. Units: metres, m/s, seconds, degrees. altitude_agl_m is above HOME, not terrain/object. Coordinate destinations declare home_relative_ned or local_ned with origin_id. Body-relative forward/right follows heading. yaw takes a nonnegative angle magnitude and explicit clockwise/right or counterclockwise/left direction; face_heading/view uses compass, absolute degrees or current. Directional observations turn horizontally.

Use supplied/measured coordinates or registered handles. Typed destination variants keep their own fields: goto reaches coordinates/saved poses; approach_target reaches measured surface standoff; overfly_target goes above measured footprint/top; orbit circles a center/object. Observation poses are neither object centers nor overhead positions. Visible objects are oriented/localized first; registered_target reuses retained geometry. Preserve explicit quantities; defaults fill only missing operating values. Missing named references require clarification. registered_waypoints initially shows catalogue availability only; get_context(include_waypoints=true) loads callable pose handles and their roles. Tools resolve these handles. Catalogue roles distinguish navigation_pose, observation_pose and explicit orbit_center.

For orbit, select camera or none for heading-only intent. Home and launch use measured references. Object standoff is minimum distance from observed hull, not center radius/global obstacle clearance; tracking reserve is reported. Unknown backside stays unknown. Nose-facing does not tilt the camera; actual visibility requires images.

The adapter supplies lease, identity, timestamps and origin, dispatches ActionService (proto/icarus/v1/drone_api.proto), and waits for terminal status; ACCEPTED is not completion. Routes/patterns delegate geometry/flight to ArduPilot. fly_pattern retains current altitude; use takeoff first for a requested height change. execute_sequence stops on failure and cannot cross observations/decisions. takeoff arms/departs when landed, changes altitude in place when airborne; it never re-arms in flight. Fresh landed/disarmed state already satisfies land.

scan_heading and scan_area own turn/path-settle-observe cycles. exit_policy: finish_at_match ends at first detector match; pause_at_match permits resuming after a nested branch; each_observation yields for arbitrary decisions; complete_coverage runs a bounded unconditional scan. Match policies require stop_on_detection and optional minimum_count. Failed observations remain pending; a paused next station need not resume after the user's condition is met. A match is not full coverage; unmatched bounded sweeps do not complete an open-ended search.

Read large/historical receipt details through read_action_result using exact action index/path; lookup is neither flight nor fresh sensing. Report each observation at its recorded stage; later telemetry does not overwrite it.
