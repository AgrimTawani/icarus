# Perimeter sweep

Use only after the operator has declared a survey boundary through a reviewed
mission/scenario. Arm and take off only when current state permits. Visit
approved waypoints through typed navigation, pause or return home when
perception is uncertain, and end with return/land according to the mission.
This is recommended composition guidance, not a route generator or authority.
